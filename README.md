# TrackMaria — Neon Sprint

En liten, spillbar TrackMania-inspirert racingdemo laget med ren HTML, CSS og JavaScript — ingen byggetrinn eller eksterne biblioteker er nødvendig.

## Spill

Åpne `index.html` i nettleseren, eller publiser repositoryet med GitHub Pages.

- **Pil venstre/høyre** eller **A/D**: styr
- **Space**: boost
- **R**: start på nytt

Demoen har en pseudo-3D-bane, neon-grafikk, timer, tre runder, boost, nedtelling og lokal beste-tid.
